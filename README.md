# Pulse — Аналитическая панель

Дашборд с выбором периода, разделами, фильтрами, поиском по операциям и экспортом демонстрационных данных в CSV.

**[Открыть демонстрацию](https://portfolio7.ru/portfolio-demos/pulse/)** · [Все проекты](https://portfolio7.ru/portfolio-demos/)

## Возможности и технологии

HTML, CSS и JavaScript. Данные для графиков и таблиц встроены в страницу.

Проект создан для портфолио. Название и данные вымышлены; реальные платежи, доставка и бронирования не выполняются. Не вводите настоящие персональные или платёжные данные.

## Локальный запуск

Нужен Python 3.10 или новее. Дополнительные Python-зависимости не требуются.

```bash
python -m http.server 8000 --bind 127.0.0.1 --directory public
```

Откройте <http://127.0.0.1:8000/>.

## Проверка

```bash
python tests/smoke.py
```

`public/` содержит интерфейс и ресурсы. Страница адаптирована для мобильных и больших экранов.
